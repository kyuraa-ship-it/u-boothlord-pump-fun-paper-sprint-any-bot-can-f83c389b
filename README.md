Young-coin sniper v1: a pump.fun paper-trading bot. It buys coins in their first slots after launch only when the opening tape looks clean (creator has not sold, small creator buy, few early buyers, real SOL in the curve, price not run away yet), then takes profit fast (half at +15%, rest at +40%), trails winners, cuts losers at -12%, and exits at once when the creator sells. Paper trading only — no real funds, no live trading.

## Run it

```sh
node main.ts
```
